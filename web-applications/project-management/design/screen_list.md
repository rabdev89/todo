# Screen List: TodoAppCertification

1. **Authentication Screens**
   - `Auth_Login`: Credential input, social login integration.
   - `Auth_Signup`: User registration, email verification notice.
2. **Dashboard Screens**
   - `Dash_Main`: List view, quick-add bar, filter sidebar/dropdown.
   - `Dash_Search_Results`: Global search results with highlighted matches.
3. **Task Detail Screens**
   - `Task_View`: Full task description, hierarchical subtask list, attachment gallery.
   - `Task_Edit_Modal`: Inline or modal editing for meta-data.
4. **User Screens**
   - `User_Profile`: Avatar management, account status.
   - `User_Settings`: Notifications, theme preferences (Dark/Light).
