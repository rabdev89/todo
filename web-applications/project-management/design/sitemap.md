# Sitemap: TodoAppCertification

## 📂 Public Layer
- `/login` - Entry point for authentication.
- `/signup` - New account registration.
- `/forgot-password` - Recovery flow.

## 📂 Private Layer (Authenticated)
- `/dashboard` - Overview of all tasks, search, and activity filtering.
- `/tasks/:id` - Detailed view of a single task, subtasks, and attachments.
- `/profile` - User settings and preferences.
- `/active-sessions` - Security overview of logged-in devices.
