# T-204 Requirements: Task Detail & Modals

## Overview
Provide users with a focused environment to view and edit task details. This includes managing subtasks and updating task metadata like descriptions and due dates.

## Requirements
- **Task Detail View (Modal or Right Drawer)**
  - Triggered by clicking a task in the dashboard.
  - Smooth animation on entrance/exit.
- **Editing Capabilities**
  - Inline editing for Title and Description.
  - Date picker for Due Date.
  - Priority dropdown.
- **Subtask Management**
  - List of child subtasks with completion toggles.
  - "Add Subtask" input field.
- **Visuals**
  - Follow "The Pristine Productivity Engine" aesthetic.
  - Clear typography hierarchy and generous padding.

## Constraints
- Changes should be saved automatically or via a clear "Save" action (UX choice).
- Modal must be accessible via keyboard (`Esc` to close).
